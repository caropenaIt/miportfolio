# miportfolio
Código y acceso a mi sitio web que es, ni más ni menos, que mi portfolio. Tanto mis trabajos como desarrolladora frontend como de QA tester los encontrarán aquí.

Puedes acceder al sitio desde Visual Studio Code, clonando este repositorio con git clone y el nombre de este repo; escribir en la consola npm install y luego npm run dev. O bien, ir al sitio web que se ve en la descripción de este repo.
